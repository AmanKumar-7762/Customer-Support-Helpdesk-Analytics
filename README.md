# Customer-Support-Helpdesk-Analytics
Analyze customers, support tickets, agents, resolutions, and customer satisfaction using SQL to improve support operations, reduce resolution time, and enhance customer experience.

This project reflects real-world SQL analysis performed by Customer Support Analysts, Operations Analysts, Service Delivery teams, Customer Success teams, and Business Intelligence professionals to improve service quality, optimize support operations, and enhance customer satisfaction.


##  Business Objectives

- Analyze support ticket volume
- Monitor support agent performance
- Measure ticket resolution time
- Identify recurring customer issues
- Analyze customer satisfaction
- Track ticket status and priority
- Compare support agents and teams
- Generate business-focused support KPIs

## 🛠️ Technologies Used

- MySQL
- SQL
- MySQL Workbench
- Git & GitHub
